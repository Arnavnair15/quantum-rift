# 🚀 Quantum Rift — 2D Space Survival Arcade Game

**Quantum Rift** is a futuristic browser-based space survival arcade game built using HTML, CSS, JavaScript, and the Canvas API.

Take control of a spaceship, dodge incoming asteroids, survive as long as possible, and beat your highest score!

## 🎮 Live Demo

**Play the game:** [Quantum Rift](https://Arnavnair15.github.io/quantum-rift/)

## ✨ Features

- 🚀 **Spaceship Controls:** Move in four directions.
- ☄️ **Asteroid Obstacles:** Avoid incoming asteroids.
- 🎯 **Real-Time Scoring:** Earn points while surviving.
- 📈 **Progressive Difficulty:** The game becomes more challenging over time.
- 🏆 **High Score System:** Save your best score using Local Storage.
- 🔄 **Restart Functionality:** Play again after game over.
- 🔊 **Sound Effects:** Optional arcade sound effects with mute/unmute controls.
- 🌌 **Futuristic UI:** Dark space theme with neon visual elements.
- 📱 **Responsive Design:** Designed to work across desktop and mobile screen sizes.

## 🕹️ Controls

| Key | Action |
|---|---|
| Arrow Up / W | Move Up |
| Arrow Down / S | Move Down |
| Arrow Left / A | Move Left |
| Arrow Right / D | Move Right |
